## How I work

- Start with a product thesis and interaction model
- Build reusable systems instead of isolated screens
- Use AI as a collaborative design and development tool
- Keep deterministic product behavior, accessibility, and human judgment explicit
- Connect design decisions to working code and deployed experiences
